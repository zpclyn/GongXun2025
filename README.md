# GongXun2025
**2025年工训赛智能物流河北省省冠开源**

PS：技术报告是直接Git推送的，.md文件直接在Github上查看可能有排版错误，建议使用Typora查看或者直接查看PDF文件。

---
### Tips:
1. 截至2026.10.27该智能物流小车在笔者见过的全部设计中依旧是最快的(**2分13秒**)成绩最高的(满分全一环)，与此同时成本也是最低的一批，笔者对此感到自豪。
2. 笔者全面开源的本意是新同学可以更快的上手，同时也可以给老队员提供一定的思路，推动整个智能物流圈子的发展，不过还是建议大家不要照搬全抄，这个设计还是有很多优化空间的。
3. 目前硬件部分的开源还做不到，涉及潘航同学的成果，除非潘航同学同意否则将无法提供硬件设计，不过笔者可以提供部分硬件设计方向，只是想要硬件设计的同学就不用加笔者联系方式了，真的提供不了。
4. 后面为了大家查看方便，或许会迁移Gitee。
5. **本开源未授权任何人借此商用，禁止任何人在未授权的情况下在任何平台售卖！**
